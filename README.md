One satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF. Entry for make.fun's "The Long Roast: Lawmakers and the File They Cannot Convert" bounty. The program writes the line to `/output/entry.txt`; a judge model compares entries two at a time on bite, aim and freshness.

## Run it

```sh
python3 main.py
```
